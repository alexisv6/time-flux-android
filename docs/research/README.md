# Research

Open questions that need investigating **before** a spec can be written — market scans, prior-art
studies, technical evaluations, product-shaping questions.

A research doc is not a spec. It ends in findings and options with trade-offs, not a decision. When
one produces enough clarity to commit to something, that becomes a numbered spec in `docs/specs/`
and the research doc is linked from it.
